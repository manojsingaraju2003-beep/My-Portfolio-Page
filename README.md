# Sambasiva Singaraju — Portfolio

Open `index.html` in a browser to view the site. No build tools or dependencies are required.

## Personalising the site

- Update colours, spacing and sizing in the variables at the top of `styles.css`.
- Replace image-placeholder blocks using the commented `<img>` examples.
- Replace every `href="#"` in `projects.html` with a real case-study, live-site or source-code URL.
- Duplicate a `.project-card` to add work, and give it `data-tags` values matching the filter buttons.
- Review the suggested goals and progress percentages; these are editable starting points rather than resume claims.
- Contact details currently mirror the supplied resume. Add a LinkedIn URL once available.

## Files

- `index.html` — About Me
- `projects.html` — Filterable projects
- `goals.html` — Goals, aspirations and progress
- `styles.css` — Shared design and responsive styling
- `script.js` — Menu, filtering, date and reveal effects
